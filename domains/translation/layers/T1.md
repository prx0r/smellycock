# LAYER T1 — the rough translation (semantic/ML floor)

*The FIRST interpretive layer: turns the raw SOURCE verse into word-gloss tokens. Batched + rough — it
churns big chunks (context-saving), hands to the next queue.*

## Contract
| | |
|---|---|
| **Consumes** | SOURCE verse (recovered via `_source_objects` → `payload.verse`) |
| **Produces** | T1 JSONL: `{object_id, tokens[], gloss{}}` |
| **Gate** | deterministic validator (source-binding: every surface ∈ source; no invented tokens) |
| **Where** | `pipeline/t1_worker.py` (`t1_generator` + `t1_validator`) |

## Hermes call (per-layer logic)
- **Agentic** (default): `chat_agentic` — writes a batch file, Hermes reads it, produces JSONL (skills).
- **`-z` streaming** (faster): `model.chat_stream` — read line-by-line, commit per verse. **Measured ~12s/verse
  vs >2min/10-verses agentic** — the preferred path for this layer.

## Queue
- Source passages with committed SOURCE but no committed T1 (the DAG backlog).

## Model / context
- `deepseek-v4-flash` (default) · 1M context · **~2993 verses/call at 90% context** (`model_registry`).

## Productivity signal
- avg time/call, verses committed/call, success rate — in the progress registry `layers[]` + benchmark.
