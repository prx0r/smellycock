# BRAINSTORM — EDUCATION + ORGANISM VISIONARY OPPORTUNITIES

*2026-08-15. Deep-dive of the education/organism/review specs (SPEC-20..32). The opportunities that
turn the deep-dive → mine → feed-essays → education pipeline into a self-improving organism.*

---

## THE ONE-LINE END-STATE (SPEC-29/28)

> **One evidence graph from Sanskrit → scholarship → human understanding.** The same gold distinction
> feeds the machine benchmark, the human exercise, the essay, the video, and the assessment. An essay
> IS a projection of the scholarly graph.

## TOP OPPORTUNITIES

### 1. Every wrong answer = a typed epistemic neighbor (SPEC-20/29)
Distractors come from the real argument graph (rival proposition, scope inflation, wrong speaker),
never an LLM. **Turns multiple-choice into diagnostic instrumentation** — a wrong answer is
proof-carrying data mapping into Pāṭala's own failure taxonomy, which diagnoses AI translation, AI
argument reconstruction, AND human understanding.

### 2. Executable corrections (SPEC-31/20) — the conceptual jewel
A scholar's correction changes the graph and the system knows what else to reconsider. Every dependent
essay/lesson/video is marked stale. **The one thing Wikipedia/Coursera/edtech structurally cannot do.**

### 3. Progressive epistemic zoom (SPEC-26/28) — the UI law
Any explanation descends reversibly: claim → argument → translation → Sanskrit → witness; the tutor
zooms up/sideways. **Lossless pedagogy** — the learner never "trusts the lesson writer."

### 4. Counterfactual / crux learning — manipulate commitments (SPEC-27/28)
The learner retracts a premise and watches the argument graph recompute live. **Philosophy's answer
to Brilliant's draggable triangle.**

### 5. The Gap Engine as the research scheduler (SPEC-21/22)
Consumers become sensors; their questions/objections/failures become canonical `Gap`s (10 types)
ranked by `Impact = D×C×U×E×R`. **Research prioritization by revealed human curiosity.**

### 6. Trajectories as first-class objects + learned pedagogy (SPEC-24/25)
"What should I learn next?" and "What should Pāṭala research next?" answered from the same data via
different policies. **Learn how people actually learn philosophy** — an empirically discovered
pedagogy graph.

### 7. The learner→scholar continuum by agency, not content (SPEC-29/28)
Seven levels from OBSERVE to ADJUDICATE to CONTRIBUTE. **A citizen-scholar funnel** where the
consumer base feeds the scholarly review system.

### 8. Deterministic counterfactual replay of the whole pipeline (SPEC-32)
`project(events ± hypothetical_events)` — "what if scholar S had rejected PROP19?" **Debugging and
audit for the organism itself.**

### 9. Consumers as distributed adversarial-review + ontology-discovery (SPEC-21/22)
Non-specialists exert falsification pressure ("does this actually follow?"), surface
`USER_EMERGENT_CONCEPT`s. **The audience becomes a distributed Reviewer 3.**

## THE REUSABLE ENGINE (build this first)

**SPEC-28's `compile_interactions(scholarly_object, targets, learner_level)`** — one kernel that turns
any mined scholarly object into a provenanced LearningPacket (claims + 6-10 interactions + diagnostic
distractors + progression + epistemic ceiling) that renders to essay, lesson, quiz, video, or tutor.

**Prove it on ONE real gold argument first (SPEC-29: "gold forces ontology"), then scale. Depth before
width.**

## THE COMPOUNDING MOATS (what competitors can't copy)

1. **Wrong-answer → epistemic-neighbor** diagnostic interactions.
2. **Executable corrections** that propagate staleness to all educational content.
3. **Progressive epistemic zoom** to the primary source.
4. **The accumulated misconception / learner-evidence / question-demand graph** — years of "what people
   misunderstand, ask, and what actually works" that no one can reproduce.
